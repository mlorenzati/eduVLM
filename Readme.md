## REST API (04_rest_api.py)
Serves the VLM over HTTP using the **OpenAI API standard**, so it can be consumed
externally by any OpenAI-compatible client (openai SDK, curl, LangChain, etc).

Start the server (on the GPU machine):
```
./04_rest_api.py --host 0.0.0.0 --port 8000
```

Endpoints:
- `GET /health` — liveness, device and GPU info
- `GET /v1/models` — list served models (OpenAI format)
- `POST /v1/chat/completions` — chat completions, supports `stream: true` (SSE)

Media is inlined as base64 data URLs in the standard OpenAI content format:

```bash
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen2.5-VL-3B-Instruct",
    "messages": [{
      "role": "user",
      "content": [
        {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,..."}},
        {"type": "text", "text": "What do you see?"}
      ]
    }],
    "max_tokens": 128
  }'
```

Consume it with the standard `openai` python package (see `05_rest_client.py`):

```python
from openai import OpenAI
client = OpenAI(base_url="http://localhost:8000/v1", api_key="eduVLM")
response = client.chat.completions.create(
    model="Qwen/Qwen2.5-VL-3B-Instruct",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

Interactive docs are auto-generated by FastAPI at `http://localhost:8000/docs`.
